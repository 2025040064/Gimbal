# K230 数字立牌联调

K230 识别白底黑字 0～10，B 题正式场地使用 0～9。它能同时识别多张牌、记录巡检结果，并在收到指定 ID 后发送该牌的中心坐标。云台归零、扫场、转动搜索和居中计时由 STM32 负责。

## 运行与接线

1. 在 CanMV IDE 中重新打开磁盘上的 `K230_数字识别_启动排障V2.py` 并运行。项目默认保持 `ENABLE_IDE_PREVIEW=True`，以 640×480 显示实时画面。启动日志应显示 `IDE_PREVIEW=True`、`[OK] FIRST_PREVIEW` 和持续的 `[STATUS]`。
2. 联调默认开启 UART3，并用 `INITIAL_TARGET_ID = 1` 锁定 1 号卡。`COMMAND_INPUT = "none"` 时只发坐标。连续三次检测确认后显示数字和框，终端每两秒打印卡片 ID、中心和尺寸。
3. 观察 `[EARLY]`、`[BOOT]`、`[OK] FIRST_PREVIEW`、`[OK] GRAY_READY` 和周期性 `[STATUS]`。出现 `[ERROR] VISION_STAGE` 时保留完整异常；如卡住或无法停止，记录最后一条输出、复位或重新上电后重新连接。第一帧出现后仍需观察画面和状态是否持续更新。
4. WonderMK 厂家随板 UART 例程配置为 UART3，GPIO50/TX、GPIO51/RX，115200、8N1。核对实际板卡接口及 TTL 电平后，接 WonderMK 外接串口 TX 到 STM32 PB11（USART3 RX），并共地。两板分别供电。启动后检查 `[OK] UART3_READY` 和 `[OK] UART3_TX`，再从 STM32 日志或 OLED 查看收到的目标坐标。
5. 已锁定的指定牌显示为绿色，其余为黄色。终端的 `TRACK,n` 和 `LOST,n` 表示锁定状态变化，`[CARD]` 输出中心与尺寸。遮挡后需重新连续确认才恢复跟踪。

## 电脑输入指令

默认 `COMMAND_INPUT = "none"`，运行预览时不读取 USB 输入。在 WonderMK 0.4.0 上，旧版脚本启用 USB 输入时曾出现 FPS 为 0、点击停止提示“忙碌中”。如果旧脚本已经卡住，先复位或重新给 K230 上电，等 COM12 重新出现后在 IDE 重新连接并打开磁盘上的新脚本。

需要电脑发送命令时，设置 `COMMAND_INPUT = "uart3"`、`INITIAL_TARGET_ID = None`。确认 IO 电平后，将 USB 转串口模块 TX 接 WonderMK 外接串口 RX（GPIO51），并共地。命令以 CR、LF 或 CRLF 结束。`"usb"` 只用于已验证支持运行中终端输入的固件和工具。

| 指令 | 处理 |
| --- | --- |
| `SCAN` | 开始 60 秒视觉巡检。每个 ID 首次确认时输出 `FOUND,n`，到期输出去重后的 `SCAN_RESULT,n1,n2,...`。 |
| `ID,3` | 选择 3 号，范围为 0～10。若正在巡检，先输出已发现的清单。 |
| `STOP` | 停止跟踪或提前结束巡检并输出清单，回到预览。 |

K230 发给 STM32 的坐标帧为 `AA 55 + 图像宽,图像高,中心x,中心y,数字框宽,数字框高 + 0D 0A`。预览、巡检和目标丢失时发送 `640,480,-1,-1,-1,-1`。丢失时保留指定 ID，重新出现并连续确认后恢复坐标。正常发送间隔至少 50 ms。ID 和巡检结果由电脑终端显示。

## 验证记录

- 电脑端的模拟测试覆盖启动选项、预览调用、数字模板、命令、巡检及遮挡重捕获；旧程序的多牌和串口帧测试不代表 V2 已在实板运行。
- 历史合成样本覆盖 9 种字体、4 种字号及 5 个角度。1,800 个样本中 1,655 个识别正确，145 个被拒识。该结果来自电脑模拟。
- 实板联调时先验证运行中 USB 输入及 STM32 能接收无目标帧，再摆 5 张不同 ID 的牌检查巡检清单。选定目标后，放入更大的干扰牌，并遮挡指定牌 2 秒后将它移到另一处，检查 STM32 在遮挡期间收到无目标帧，随后只恢复指定牌的坐标。正式光照、距离、延迟以及整机扫场、居中计时和原始视频仍需实测。

## WonderMK I2C 接口核对

用户提供的 WonderMK 基础课程 `源码/IIC.py` 配置 GPIO11 为 I2C2 SCL、GPIO12 为 I2C2 SDA，采用 `I2C_Slave` 和 7 位地址 `0x10`。该示例需要实际运行检查 `I2C_Slave.list()` 是否包含可用设备。

同套资料的原理图第 4 页中，I2C 接口 J4 的 1 脚为 SCL、2 脚为 SDA、3 脚为 GND、4 脚为 5V。模块可继续通过 Type-C 供电，只连接信号与共地时不要再接 J4 的 5V。以实物板卡与原理图对应为前提核对针脚。

STM32 闭环工程使用 PB6/SCL、PB7/SDA 通过软件 I2C 连接地址为 `0x68` 的 MPU6050。WonderMK 与 MPU6050 地址不同，可以研究共用该总线。当前软件 I2C 没有检查 SCL 时钟拉伸，且 STM32 的 K230 接收程序仍使用 USART3，直接接线后无法完成通信。需要修改和测试两端软件，再验证电平、总线时序和实物通信。
