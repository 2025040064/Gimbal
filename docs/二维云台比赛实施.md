STM32 负责任务、运动和 OLED，K230 负责数字识别。任务与 ID 烧录前设置，手动摆到水平朝前后复位启动。

## 上板顺序

1. K230 使用 [k230视觉云台.py](../k230视觉云台.py)，启动标识为 `WONDERMK_LINK_V3`。保持 640×480、`ENABLE_IDE_PREVIEW=True` 和 `COMMAND_INPUT="uart3"`，运行后检查预览及 `[STATUS]`。
2. 保持 GPIO50/TX → STM32 PB11/RX。核对两端信号电平后，补接 STM32 PB10/TX → GPIO51/RX，保留共地和分别供电。串口参数为 115200 8N1。
3. 当前 HEX 为电机 B 项固件。先将云台摆到水平朝前；K230 运行后复位 STM32，检查 K230 打印 `[RX] STOP`、`[RX] ID,1`。先将 1 号卡放在画面中心附近，再小幅左右、上下移动，检查云台使目标回到中心；反向追离目标时停止运行，再调整对应轴的 `*_POSITIVE_CW`。B 项获取目标限时 15 秒，连续居中 1 秒后进入 5 秒保持统计，完成显示 `DONE`，重新复位开始下一次。若显示 `LINK FAULT`，检查双向接线及 K230 状态输出。
4. 两轴当前均使用已确认的 20000 脉冲/圈，`MOTION_CALIBRATED=1`。更换电机、细分或传动后须重新确认比例与方向。需要单轴测量时在 `contest_config.h` 选择 `J`：默认水平轴低速发 100 脉冲，对应直连轴 1.8°；修改后重新编译烧录。水平正方向对应图像右侧，俯仰正方向对应图像下侧。
5. 每次赛题测试前配置 `CONTEST_MODE` 和 `CONTEST_TARGET_ID`，重新构建和烧录。启动前手动摆回零位。每次测试开始后，STM32 先发送 STOP 同步，再发送 SCAN 或 ID 指令。K230 回传带模式、目标 ID 和观测序号的坐标帧。六或七字段旧帧只用于显示。

## 计时与验收

| 项目 | 软件记录与实板检查 |
| --- | --- |
| A | 以 60 秒截止时的 OLED ID 清单为准。用随机分布的五张牌检查覆盖、去重和误检。 |
| B | 每个目标从统一零位开始。15 秒内达到连续居中 1 秒后，统计接下来 5 秒的居中毫秒数。中心阈值暂设每轴 ±12 px，最终以裁判口径为准。 |
| C | 前 15 秒允许获取目标，OLED 显示 `MOVE NOW` 后开始本机 15 秒计时。水平和倾斜轨迹各运行一次。本机识别中断只记为提示，是否实际出画和裁判开始时刻以视频复核。 |
| D | 首次锁定后，OLED 的 `WAIT LOSS` 表示可遮挡。识别到目标丢失后暂停，随后搜索同一 ID。软件以检测到丢失后约 2 秒作为重现时间估计，实际重现时刻及 8 秒截止以原始视频复核。 |

当前修复脚本不含文件录像。旧版的 `/data/gimbal_NNNN/camera.mjpeg`、`events.csv` 录制设计不能作为当前功能使用；需在电机联调稳定后接入，再验证写盘时的识别周期、帧间距和原始视频。正式比赛计时仍需视频复核。
