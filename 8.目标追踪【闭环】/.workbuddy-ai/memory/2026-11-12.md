# 2026-11-12 工作日志

## 视觉方案调研（YOLOv8 数字识别，用于云台目标追踪竞赛题）
- 硬件：STM32 + K230（CanMV MicroPython）视觉下位机，串口协议已有 VisionFrame{width,height,x,y,box_w,box_h,ids,mode,id,sequence}，见 HARDWARE/K230/k230.h。
- 竞赛要求：5 个静止带 ID 目标，巡检/指定锁定/移动跟踪/遮挡重捕获。ID 识别放 K230 上做。
- 调研结论：YOLOv8n 检测（类别即 ID）→ ONNX → nncase 2.9.0 转 kmodel（INT8+校准集）→ K230 KPU 推理 320x320 → 串口发坐标+ID。与现有 VisionFrame 协议完全契合。
- 关键参考：
  - GitHub idinging/mnisttyolo8（MNIST→YOLO 格式转换+训练+摄像头实时检测）
  - 嘉楠官方 yolov8n 检测例程 kendryte.com/k230_canmv
  - nncase 版本必须 2.9.0 与固件锁死；无 ncc 命令行，用 python 转换脚本
  - 嘉楠有免费在线训练平台 kendryte.com/zh/training/start
- 已确认：目标 = 白底黑字 0-9 数字牌，数据集用户自己实拍采集，10 类。
- STM32 侧已完整（状态机/协议/电机），不动代码；缺 K230 视觉脚本 + 模型。
- 协议规格（k230.c 为准）：K230→STM32 帧 `0xAA 0x55 w,h,x,y,bw,bh,ids,mode,id,seq\r\n`；STM32→K230 命令 SCAN\n / ID,n\n / STOP\n，200ms 重发。
- 已建《架构方案.md》于任务根目录，8 阶段计划，当前进入阶段 2（数据采集）。
- 训练框架定为 ultralytics 官方仓库（用户指定参考 github.com/ultralytics/ultralytics）；训练/导出命令已写入架构方案 §4.3/4.4（yolo train + yolo export onnx, opset=12, dynamic=False）。
