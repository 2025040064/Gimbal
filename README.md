# 二维视觉云台

项目包含 STM32 云台工程、K230 数字识别实验和硬件资料。不同分支记录了不同阶段的固件实现；请先核对具体分支和硬件，再用于实机。

- [数字识别模型、数据与脚本](数字识别/README.md)：包括 K230 使用的 KMODEL、原始模型、校准图片、训练数据和测试脚本。
- [项目资料](项目资料/README.md)：包含物资文档、PCB 工程、机械模型和历史说明。
- `7.目标追踪【开环】/`、`8.目标追踪【闭环】/`：已有 STM32 工程。
- `docs/`、`tests/`：历史联调说明与测试。

此前 K230 曾加载模型并识别数字；摄像头偶发启动卡住、STM32 与云台的完整闭环表现仍需实物验证。竞赛开发分支中的 `tests/test_k230_preview_startup.py` 引用的 `K230_数字识别_启动排障V2.py` 当前不在工作区，该测试不能作为已通过的检查。
