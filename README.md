# Gimbal｜STM32 + K230 双轴视觉追踪云台

基于 **STM32F103C8T6（HAL）** 和 **K230（CanMV）** 的双轴云台实验项目。仓库按从基础外设到视觉目标追踪的阶段保留 Keil/CubeMX 工程，并存放 PCB、机械模型与 K230 脚本。

> 当前状态：仓库已有闭环视觉追踪阶段的源码与硬件设计资料，**不代表已完成实物测试或全部功能验收**。“闭环”现指视觉目标位置误差反馈，不应等同于已经完成 MPU6050 惯性稳定闭环。

## 运行架构（按当前代码）

```text
K230 摄像头 → 检测红色色块 → UART2 (115200)
                                 ↓
                         STM32 USART3
摇杆 ── ADC ──┐                  │
              ├── 控制选择/追踪逻辑 ── PUL/DIR/ENA ── 两路步进电机驱动接口
MPU6050 ─ I²C┤
              └── OLED 显示与状态输出
```

K230 脚本的数据帧格式：`AA 55` + ASCII `screen_w,screen_h,target_x,target_y,target_w,target_h` + `0D 0A`；无目标时坐标/目标宽高为 `-1`。代码使用 STM32 USART3 115200 接收，运行前请核对实际板卡、引脚电平和供电。具体物料和接口检查见 [BOM](docs/BOM_物资采购清单.md)。

## 构建及整理说明

- STM32 各阶段是**独立工程**，采用 HAL 库。请打开各阶段 `MDK-ARM` 内的 Keil 工程文件（`.uvprojx`）或 CubeMX `LED.ioc`，不要把 8 个阶段的源文件直接混编。
- 有些外设初始化在 `HARDWARE/` 与手写代码中完成，`.ioc` 并非完整的运行时配置清单；重新生成代码前备份并逐项核对。
- 历史代码及 `Drivers/`、`HARDWARE/`、PCB、STEP 均**未因文档整理而改动**。
- 仓库已有跟踪的构建产物不会被新增 `.gitignore` 自动删除；是否做历史构建文件清理由仓库维护者后续决定。
- 原工程目录中的 `HARDWARE/MORTOR` 是现有路径拼写；为避免破坏工程引用，此次没有擅自重命名。

## 采购与安全提醒

采购前核实两个步进电机是否内置 PUL/DIR/ENA 驱动、24 V 供电方案与低压模块兼容性，并将 PCB 元件表和实物逐项核对。请采用符合设备规格的合规供电设备，接线测试需要防短路与机械运动保护。
