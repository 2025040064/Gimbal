# Gimbal｜STM32 + K230 双轴视觉追踪云台

基于 STM32F103C8T6（HAL） 和 K230（CanMV） 的双轴云台实验项目。仓库按从基础外设到视觉目标追踪的阶段保留 Keil/CubeMX 工程，并存放 PCB、机械模型与 K230 脚本。

已经完成 MPU6050 惯性稳定闭环。

## 快速导航

- **[完整物资清单 / 采购前核查（BOM）](docs/BOM_物资采购清单.md)** — 汇总 `wuzi.docx` 13 类物资、对应源码及待核实的电机驱动、供电、元件级 BOM。
- **[闭环追踪阶段工程](8.目标追踪【闭环】/)** — STM32 HAL 实验工程（Keil MDK-ARM）；历史阶段仍完整保留。
- **[K230 视觉程序](k230视觉云台.py)** — 红色目标检测并经 UART 发送目标坐标。
- **[原理图](原理图.pdf)** / **[PCB 工程](ProPrj_云台PCB文件_10.1_2026-10-01.epro)** / **[电子元件 BOM（xlsx）](BOM_Board1_Schematic1_2026-10-01.xlsx)**。
- **[整机机械模型](云台.step)** / **[底盘 3MF](底盘.3mf)**。




K230 脚本的数据帧格式：`AA 55` + ASCII `screen_w,screen_h,target_x,target_y,target_w,target_h` + `0D 0A`；无目标时坐标/目标宽高为 `-1`。代码使用 STM32 USART3 115200 接收，运行前请核对实际板卡、引脚电平和供电。具体物料和接口检查见 [BOM](docs/BOM_物资采购清单.md)。
